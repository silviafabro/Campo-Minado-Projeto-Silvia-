# Campo-Minado-Projeto-Silvia-
Projeto Campo Minado desenvolvido em Java para a disciplina de Programação Orientada a Objetos. Possui tabuleiro configurável, minas aleatórias, contagem de vizinhas, efeito cascata, bandeiras e detecção de vitória ou derrota. Inclui versão em console, interface gráfica Swing e testes unitários com JUnit.
